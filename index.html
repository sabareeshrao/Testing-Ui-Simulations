01 / THE BIG PICTURE

How your code becomes output

A Java program does not jump straight from text to the screen. It passes through a compiler and the Java Virtual Machine (JVM).

STAGE 01

Source code

Human-readable Java that you write in an editor.

Main.java
STAGE 02

Compiler

The javac tool checks and compiles your Java code.

javac Main.java
STAGE 03

Bytecode

The compiled .class file contains instructions for the JVM.

Main.class
STAGE 04

JVM runs it

The JVM executes the program and prints the message.

java Main

Note: The class file contains JVM bytecode, not a separate copy of the original Java source text.

02 / CODE ANATOMY

Decode the five important pieces

Every keyword, name, and symbol has a job. These are the building blocks that make the small program work.

01 / CLASS
public class Main

The program's container

Declares a publicly accessible class named Main. The code lives inside its curly braces. The public class name matches Main.java.

02 / ENTRY POINT
public static void main

Where execution begins

The launcher calls main. public makes it accessible, static means no Main object is needed, and void means it returns no value.

03 / INPUT
String[] args

Command-line arguments

An array of text values that can be passed when starting the program. This example does not read args, so its value does not affect the message.

04 / ACTION
System.out.println(...);

Print a message

Sends text to standard output and adds a newline afterward. The semicolon marks the end of this Java statement.

05 / DATA
"Hello World"

A String literal

Double quotation marks tell Java this is text. The characters Hello World appear in the output without those quotation marks.

06 / STRUCTURE
{ }

Curly braces make blocks

The outer pair surrounds the class. The inner pair surrounds the main method. Each opening brace has a matching closing brace.

03 / ZOOM INTO LINE 3

What does System.out.println mean?

It looks like one long command, but it is a chain of three named parts. Follow it from left to right.

System.out.println("Hello World");
PART A / CLASSSystem

Java's built-in System class provides access to standard input, output, and other system features.

PART B / OUTPUT STREAM.out

A static field containing a PrintStream connected to standard output.

PART C / METHOD.println()

A method that prints its argument, then ends the output line.

04 / BEHIND THE SCENES

Two moments that matter

Compilation prepares the program. Execution actually runs it. They are different operations.

01. Compile the file
The Java compiler turns your source code into a class file of JVM bytecode.
Main.java→javac→Main.class
02. Run the class
The Java launcher starts the JVM, which executes main() and reaches the println statement.
TERMINAL · STANDARD OUTPUT
$ java Main
Hello World
THE BIG TAKEAWAYCode → Compile → Run → Output

Your Java file defines a class and its main method. The compiler produces bytecode. The JVM executes main(), and println writes Hello World to the console.
