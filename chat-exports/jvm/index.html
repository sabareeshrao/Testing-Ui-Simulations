JVM — Java Virtual Machine

The JVM is the runtime engine that executes Java bytecode on your computer.

It enables Java's principle: Write Once, Run Anywhere.

JDK vs. JRE vs. JVM

Conceptual relationship. Modern Java distributions, including Java 21, generally use JDKs or custom runtime images rather than a separately distributed JRE.

Remember: JDK develops Java programs. The runtime provides the required libraries. JVM executes Java bytecode, manages runtime memory and enables platform independence.
