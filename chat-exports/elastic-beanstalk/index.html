AWS Elastic Beanstalk

Elastic Beanstalk is an AWS service that deploys your application and automatically provisions and manages the infrastructure needed to run it.

You build the application. Beanstalk handles much of the infrastructure.

Beanstalk itself has no additional service fee. You pay for the AWS resources you consume.

Remember: EC2 gives you a server. Elastic Beanstalk gives you a managed application deployment environment. This example uses Beanstalk Standard; AWS also offers a Cluster mode based on Amazon EKS.
