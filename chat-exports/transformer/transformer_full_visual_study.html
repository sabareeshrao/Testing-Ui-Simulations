Transformer — the architecture behind modern AI

A Transformer is a deep learning architecture that uses attention mechanisms to understand relationships between elements in a sequence and transform them into meaningful representations.

Transformers are the foundation of many modern language models, including GPT, Claude, Gemini, BERT and Llama.

Introduced in 2017 through the research paper Attention Is All You Need, the original Transformer replaced recurrent sequence processing with an attention-based architecture.

Simplified decoder-only Transformer generating the next token.

1. Why Transformers were introduced

Earlier recurrent neural networks process sequences one step at a time. Transformers can calculate attention for many input positions in parallel, making training more parallelizable and helping model long-range relationships.

RNN — sequential processing
Each hidden state depends on the previous state.
Transformer — attention
Tokens exchange information through attention.

Parallel processing during training does not mean that autoregressive text generation happens all at once. Standard generation still predicts tokens sequentially.

4. What are Query, Key and Value (Q, K, V)?

For every token, a self-attention layer constructs three vectors using learned linear projections.

Q
Query
What information am I looking for?
K
Key
How can other tokens match me?
V
Value
What information do I contribute?
Q = XWQ,   K = XWK,   V = XWV

The query is compared with keys to determine attention weights. The values are then combined using those weights. Reference.

5. Self-attention — the heart of a Transformer

Self-attention allows a token to gather information from other tokens in the same sequence.

Consider the sentence:

The cat sat

The representation of "sat" can incorporate information about "cat" rather than processing the word in isolation.

How attention is calculated

Attention(Q,K,V) = softmax(QKᵀ√dₖ)V

Here, dₖ is the dimension of the key vector. Scaling helps keep dot products from becoming excessively large. Reference.

6. Multi-head attention

A single attention mechanism captures one learned pattern of relationships. Multi-head attention allows several different projections and attention calculations to run in parallel.

Illustrative attention patterns. Each head has its own learned projections; head outputs are combined and projected back into the model dimension.

Different heads may learn different relationships, such as nearby words, grammatical dependencies or longer-distance context. They are not explicitly assigned those roles.

Encoder-only
Build contextual representations of an input sequence.

Decoder-only
Predict the next token using previous tokens.
Examples: GPT · Llama
Encoder-decoder
Encode the input and generate a separate output sequence using cross-attention.

11. Why Transformers consume so much memory

In ordinary dense self-attention, a sequence of N tokens produces N × N attention scores per head.

Attention scores
Float32 score matrix
Doubling sequence length creates four times as many score entries in dense attention.
Illustrative logarithmically sized bars. Memory estimate is for one explicitly stored score matrix, one head and one sequence; it excludes all other model memory.

Optimized implementations such as FlashAttention avoid materializing the entire attention matrix in high-bandwidth memory. KV caching saves previously computed keys and values during autoregressive inference.

12. Implement attention using Python

Here is the fundamental attention operation using PyTorch, without building an entire language model.

python 
import torch
import math

Q = torch.tensor([
    [0.2, 0.4],
    [1.0, 0.2],
    [0.9, 0.8]
])

K = torch.tensor([
    [0.3, 0.2],
    [1.0, 0.6],
    [0.2, 1.0]
])

V = torch.tensor([
    [0.1, 0.4],
    [0.9, 0.2],
    [0.4, 0.8]
])

scores = Q @ K.T / math.sqrt(K.size(-1))

mask = torch.triu(
    torch.ones(3, 3, dtype=torch.bool),
    diagonal=1
)

scores = scores.masked_fill(mask, float("-inf"))
weights = torch.softmax(scores, dim=-1)
output = weights @ V

print(weights)
print(output)
Tensor shape transformation
Scaling and masking occur before softmax. The example uses the same vectors as the attention simulator.

13. Transformer vs vector database vs RAG

These concepts work together, but they have very different responsibilities.

Neural network architecture that processes contextual representations and can generate tokens.
Vector database
Stores and retrieves similar embeddings.
RAG
Retrieves relevant knowledge and supplies it to a generation model.

15. Complete mental model

Remember: A Transformer is the architecture. Attention is its mechanism for exchanging contextual information. A language model uses that architecture to predict tokens, while applications such as RAG can supply external knowledge.
