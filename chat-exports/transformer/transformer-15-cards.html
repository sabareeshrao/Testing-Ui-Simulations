How Transformer works

Inside a GPT-style, decoder-only Transformer. Numerical values are simplified examples.

01 · Tokenization

The sentence is split into tokens. Each token receives a numerical ID from the tokenizer's vocabulary.

02 · Embedding lookup

The ID selects a learned vector containing numerical features. Real Transformers typically use hundreds or thousands of dimensions.

03 · Positional information

Position matters. Rotary positional embeddings (RoPE), for example, rotate query and key vector components according to token position.

04 · Query, Key and Value

Three learned weight matrices transform each token representation into a Query, Key and Value vector.

05 · Attention scores

S = QKᵀ√dk

Each query is compared with every key using a dot product. Higher scores indicate stronger attention compatibility.

06 · Causal masking

A GPT-style Transformer cannot look at future tokens. Masked attention scores become negative infinity before softmax.

07 · Softmax normalization

Softmax converts the scores into attention weights that add up to 100%. Here, the token “cat” receives the most attention.

08 · Combining value vectors

Every value vector is multiplied by its attention weight. Their weighted sum creates a new context-aware representation.

09 · Multi-head attention

Multiple attention heads work in parallel using different learned projections, allowing the model to capture different contextual relationships.

10 · Head concatenation & projection

Head outputs are joined and multiplied by a learned output matrix to produce one unified representation.

11 · Residual connection & normalization

Normalization stabilizes computation. The residual connection adds the attention result to the original representation. Shown here is the pre-normalization design.

12 · Feed-forward network

Each token independently passes through a neural network that expands its dimensions, applies a nonlinear transformation and projects it back.

13 · Stacking Transformer blocks

Attention, feed-forward networks, normalization and residual connections repeat across many layers, progressively transforming the token representations.

14 · Language modeling head

The final representation is projected into vocabulary-sized logits. Softmax produces next-token probabilities, and a decoding strategy selects a token.

15 · Autoregressive generation

Each generated token becomes part of the context for predicting the next token. This process repeats until a stopping condition is reached.
