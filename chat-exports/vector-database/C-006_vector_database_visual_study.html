Vector Database

A vector database is a database designed to store, index and search numerical representations of data called vectors.

Unlike conventional databases, which typically search for exact values, vector databases can find information based on similarity and meaning when used with suitable embeddings.

9. What is vector indexing?

Imagine searching through one million stored vectors.

Comparing the query against every vector can become expensive. Vector indexes help narrow the search to promising candidates.

Brute-force search
Compares against every stored vector.
Exact search
Indexed search
Explores promising regions or neighbors.
Often approximate search

This is commonly called Approximate Nearest Neighbor (ANN) search.

It trades some certainty of finding the exact nearest neighbors for faster retrieval.

13. Vector database in RAG architecture

RAG stands for Retrieval-Augmented Generation. It supplies an LLM with retrieved information to help generate a grounded response.

The vector database retrieves relevant information. The LLM generates the answer using that information. They have different responsibilities.

15. Vector database using Python

A simple example using Chroma and a sentence-transformer embedding model.

Install dependencies
bash
pip install chromadb sentence-transformers
python
import chromadb
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("all-MiniLM-L6-v2")

client = chromadb.Client()

collection = client.create_collection(
    name="knowledge_base"
)
Step 1 — Initialize
Load the embedding model and create an in-memory vector collection.
python
documents = [
    "Java supports multithreading",
    "Spring Boot builds Java applications",
    "Pizza is an Italian dish"
]

vectors = model.encode(documents).tolist()
Step 2 — Generate embeddings
Convert the three documents into numerical vectors.
Each document receives an embedding from the same model.
python
collection.add(
    ids=["doc1", "doc2", "doc3"],
    documents=documents,
    embeddings=vectors
)
Step 3 — Store vectors
Insert the IDs, original documents and corresponding embeddings.
python
query = "How do threads work in Java?"

query_vector = model.encode([query]).tolist()

results = collection.query(
    query_embeddings=query_vector,
    n_results=2
)

print(results["documents"])
Step 4 — Search
Convert the question into a vector and retrieve its nearest matches.
