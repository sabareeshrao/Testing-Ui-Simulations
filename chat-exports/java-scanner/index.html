01 · What is Scanner?

Scanner is a Java utility class that reads and parses input from sources such as keyboards, files and strings.

02 · Creating a Scanner

import java.util.Scanner;
Scanner sc = new Scanner(System.in);

System.in represents the standard input stream. The Scanner object reads from that stream.

03 · Inside the input buffer

Scanner buffers input and separates tokens using whitespace as its default delimiter.

04 · next() vs nextLine()

next() reads one whitespace-delimited token. nextLine() reads the remaining characters on the current line.

05 · Reading a String

String name = sc.nextLine();

Use nextLine() when the input may contain spaces, such as a full name or address.

06 · Reading an integer

int age = sc.nextInt();

Converts the next token into a 32-bit signed integer. Invalid or out-of-range input causes InputMismatchException.

07 · Reading decimal numbers

double price = sc.nextDouble();

Reads floating-point input using the Scanner's locale. The decimal separator in this example is a period.

08 · Reading boolean values

boolean active = sc.nextBoolean();

Accepts true or false, ignoring case. Inputs such as yes, no and 1 are not valid booleans.

09 · Reading a single character

char letter = sc.next().charAt(0);

Scanner has no nextChar() method. Read a token and extract its first character using charAt(0).

10 · Reading multiple inputs

String name = sc.next();
int age = sc.nextInt();
double salary = sc.nextDouble();

Each method consumes the next appropriate token, advancing Scanner's reading position.

11 · The infamous newline problem

int age = sc.nextInt();
String name = sc.nextLine();
// name is an empty string

nextInt() consumes the number, but not the following newline. nextLine() then consumes the remainder of that line, which may be empty.

12 · Fixing the newline problem

int age = sc.nextInt();
sc.nextLine(); // consume remainder
String name = sc.nextLine();

When the name is expected on the following line, add an extra nextLine() to consume the remainder of the numeric input line.

13 · Validating input before reading

if (sc.hasNextInt()) {
    int age = sc.nextInt();
}

hasNextInt() checks the upcoming token without consuming it. It helps avoid InputMismatchException.

14 · Retry until valid input

while (sc.hasNext() && !sc.hasNextInt()) {
    sc.next(); // discard invalid token
}
if (sc.hasNextInt()) {
    int age = sc.nextInt();
}

Discard invalid tokens before retrying. Otherwise, Scanner keeps checking the same invalid token.

15 · Scanner resource lifecycle

Closing a Scanner releases its associated resources. A Scanner wrapping System.in also closes System.in, so close it only when standard input is no longer needed.
