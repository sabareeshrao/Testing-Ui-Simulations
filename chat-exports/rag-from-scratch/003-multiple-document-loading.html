Step 4 — Complete loader.py

ఇప్పుడు నీ loader.py మొత్తం ఇలా ఉండాలి.

Python
from pathlib import Path


def load_document(path: Path) -> str:
    return path.read_text(encoding="utf-8")


def load_documents(directory: Path) -> dict[str, str]:
    documents = {}
    for path in sorted(directory.glob("*.txt")):
        if path.is_file():
            documents[path.name] = load_document(path)
    return documents

గమనించు, మనం మొదటి function ని రెండో function లో reuse చేస్తున్నాం.

ఒకే functionality కోసం మళ్ళీ code రాయాల్సిన అవసరం లేదు. దీనినే code reusability అంటారు.

Step 6 — Complete main.py

Python
from pathlib import Path
from loader import load_documents


def main():
    print("RAG Application Started")

    data_directory = Path(__file__).resolve().parent / "data"
    documents = load_documents(data_directory)
    print(f"Loaded {len(documents)} documents")
    for name, content in documents.items():
        print(f"\nSource: {name}")
        print(content)


if __name__ == "__main__":
    main()
