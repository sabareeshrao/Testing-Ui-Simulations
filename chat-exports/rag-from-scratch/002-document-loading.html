Step 3 — Create document loader

Timestamp: D01 00:22–00:27

Project root లో loader.py అనే కొత్త file create చెయ్యి. data folder లో కాదు.

loader.py
Python
from pathlib import Path


def load_document(path: Path) -> str:
    return path.read_text(encoding="utf-8")

ఇందులో ప్రతి line ని అర్థం చేసుకుందాం.

Line 1

Python
from pathlib import Path

pathlib అనేది Python standard library module.

Computer లో ఉన్న files, directories, file paths తో పని చేయడానికి ఉపయోగపడుతుంది.

Java లో నువ్వు ఉపయోగించే java.nio.file.Path లాంటి concept ఇది.

ఉదాహరణకు:

Python
Path("data/ai.txt")

ఇది file location ని represent చేసే Path object ని create చేస్తుంది. ఇంకా file ని చదవదు.

Line 4

Python
def load_document(path: Path) -> str:
Elementఅర్థం
defFunction define చేస్తుంది
load_documentFunction పేరు
pathInput parameter
PathExpected input type
-> strExpected return type

ఈ function కి ఒక file location ఇస్తే, అందులోని information ని string రూపంలో return చేయాలి అనేది మన design.

Python లో ఈ type hints ని runtime ఆటోమేటిక్‌గా enforce చేయదు.

Line 5

Python
return path.read_text(encoding="utf-8")

ఇది మన RAG application లో మొదటి అసలైన functionality.

read_text() file ని open చేసి, అందులోని text మొత్తాన్ని చదివి, file ని close చేసి, text ని return చేస్తుంది.

encoding="utf-8" ఉపయోగించడం వల్ల English మాత్రమే కాకుండా Telugu, Hindi వంటి భాషల్లో ఉన్న text files కూడా UTF-8 format లో ఉంటే చదవగలుగుతాం.

Step 4 — Connect loader to main.py

Timestamp: D01 00:28–00:35

ఇప్పుడు మనం కొత్త file create చేయడం లేదు. ఇంతకుముందు రాసిన main.py దగ్గరికి తిరిగి వెళ్తున్నాం.

ఇందులో కొత్తగా రెండు imports add చెయ్యి.

Python
from pathlib import Path
from loader import load_document

loader.py లో మనం రాసిన function ని main.py లో ఉపయోగించడానికి import చేస్తున్నాం.

ఇప్పుడు main() function లో ఈ మూడు lines add చెయ్యి.

New code line 1

Python
document_path = Path(__file__).resolve().parent / "data" / "ai.txt"

ఈ ఒక్క line లో multiple operations జరుగుతున్నాయి.

ExpressionResult example
__file__main.py file path
Path(__file__)Path object
.resolve()Absolute file path
.parentProject directory
/ "data"Data directory
/ "ai.txt"Document location

/ ఇక్కడ division operator లాగా పనిచేయదు. Path object తో ఉపయోగిస్తున్నాం కాబట్టి file paths ని join చేస్తుంది.

దీనివల్ల project ని వేరే location కి move చేసినా document location సరిగ్గా గుర్తించగలుగుతుంది.

New code line 2

Python
content = load_document(document_path)

ఇక్కడ execution main.py నుంచి loader.py లోని function కి వెళ్తుంది.

Function document ని చదివి, text ని తిరిగి పంపిస్తుంది. ఆ text content variable లో store అవుతుంది.

New code line 3

Python
print(content)

Document నిజంగా load అయిందా లేదా verify చేయడానికి console లో print చేస్తున్నాం.

Step 5 — Complete main.py

Python
from pathlib import Path
from loader import load_document


def main():
    print("RAG Application Started")

    document_path = Path(__file__).resolve().parent / "data" / "ai.txt"
    content = load_document(document_path)
    print(content)


if __name__ == "__main__":
    main()
