Step 3 — Create loader.py

loader.py
from pathlib import Path


def load_document(path: Path) -> str:
    return path.read_text(encoding="utf-8")

Project root లో loader.py create చెయ్యి. pathlib Python standard library module; Java java.nio.file.Path లాంటి concept. Path('data/ai.txt') file location represent చేస్తుంది, ఇంకా file చదవదు.

/ ఇక్కడ division కాదు; Path object తో file paths join చేస్తుంది. Project move చేసినా document location సరిగ్గా resolve అవుతుంది. load_document(document_path) execution loader.py కి వెళ్తుంది; return text content లో store అవుతుంది. print(content) document load అయినట్లు verify చేస్తుంది.

Step 5 — Complete main.py

main.py
from pathlib import Path
from loader import load_document


def main():
    print("RAG Application Started")

    document_path = Path(__file__).resolve().parent / "data" / "ai.txt"
    content = load_document(document_path)
    print(content)


if __name__ == "__main__":
    main()
