మనం ఇప్పుడు VS Code లో RAG — Retrieval-Augmented Generation system ని పూర్తిగా scratch నుంచి build చేద్దాం. కేవలం libraries install చేసి code copy-paste చేయడం కాదు. ఒక AI Developer నిజంగా project ఎలా build చేస్తాడో అదే logical development order లో వెళ్దాం. ప్రతి file, code line, ఎందుకు అవసరం, తర్వాతి functionality కి ఎలా ఉపయోగపడుతుందో చూద్దాం.

అసలు మనం ఏం build చేస్తున్నాం?

మన సొంత documents ఆధారంగా ప్రశ్నలకు సమాధానాలు ఇచ్చే AI application. ఉదాహరణకు మన దగ్గర 100 AI documents ఉన్నాయనుకుందాం. User ఒక question అడిగాడు:
What is Gradient Descent?

మన application ఆ 100 documents నుంచి సంబంధిత information వెతికి, దానిని LLM కి అందించి, సమాధానం generate చేస్తుంది.

ఈ architecture లో ప్రతి component ని మనమే ఒక్కొక్కటిగా implement చేస్తాం.

Project development roadmap

Step 001 — Project initialization

1.1 — VS Code terminal open చెయ్యి

Terminal → New Terminal లేదా Ctrl + Shift + backtick. Terminal అంటే operating system కి commands ఇచ్చే interface. ఇక్కడ folders create చేయడం, packages install చేయడం, Python programs execute చేయడం చేస్తాం.

1.2 — Python version

ముందుగా Python install అయిందో లేదో check చేద్దాం.

Bash
python --version

Windows లో python command పనిచేయకపోతే:

Bash
py --version

Mac/Linux లో:

Bash
python3 --version

Python 3.11 లేదా 3.12 ఉంటే ప్రారంభించవచ్చు. Version number మారవచ్చు.

1.3 — Project directory

Bash
mkdir rag-from-scratch

mkdir అంటే Make Directory. మన RAG project కోసం folder create చేస్తున్నాం.

Bash
cd rag-from-scratch

cd అంటే Change Directory. మనం create చేసిన folder లోకి వెళ్తున్నాం.

Bash
code .

code . ప్రస్తుత folder ని VS Code లో open చేస్తుంది. Command పనిచేయకపోతే File → Open Folder ద్వారా open చెయ్యి.

1.4 — Virtual environment

Bash
python -m venv .venv

ప్రతి project కి వేర్వేరు library versions అవసరం కావచ్చు. .venv వల్ల ఒక project dependencies ఇంకొక project మీద ప్రభావం చూపకుండా maintain చేయవచ్చు.

CodeMeaning
pythonPython interpreter
-mModule ని execute చేయడం
venvVirtual environment module
.venvEnvironment folder పేరు

Virtual environment ఎందుకు అవసరం?

నీ computer లో మూడు AI projects ఉన్నాయనుకుందాం. ఒక్కో project కి ఒక్కో version library అవసరం కావచ్చు.

Virtual environment వల్ల ఒక project లో install చేసిన libraries ఇంకొక project మీద ప్రభావం చూపకుండా maintain చేయవచ్చు.

1.5 — Virtual environment activate చెయ్యి

Windows PowerShell:

PowerShell
.\.venv\Scripts\Activate.ps1

Mac / Linux:

Bash
source .venv/bin/activate

Terminal ప్రారంభంలో (.venv) కనిపిస్తే activate అయింది.

Step 002 — మన మొదటి Python file

Explorer లో New File ద్వారా main.py create చెయ్యి.

Python
def main():
    print("RAG Application Started")


if __name__ == "__main__":
    main()

2.2 — Code explanation

Python
def main():

ప్రధాన operations coordinate చేసే function. తర్వాత documents, chunks, embeddings, questions ఇక్కడ నుంచి ప్రారంభమవుతాయి.

Python
print("RAG Application Started")

Application execute అవుతుందో verify చేస్తాం.

Python
if __name__ == "__main__":

Direct execution లో __name__ value __main__. Import చేసినప్పుడు application అనవసరంగా start కాదు.

Python
main()

ఇక్కడ మనం define చేసిన main function ని call చేస్తున్నాం.
