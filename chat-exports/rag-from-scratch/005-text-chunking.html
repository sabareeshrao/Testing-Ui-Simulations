Stage 005 — Text Chunking

D01 01:30 onwards · Document preparation

ఇప్పటివరకు documents automatically load చేసి, వాటిలోని unnecessary whitespace ని clean చేశాం.

మన దగ్గర ఒక 500 pages document ఉందనుకో. మొత్తం document ని LLM కి పంపితే context limit, cost, unrelated information వంటి సమస్యలు రావచ్చు.

అందుకే పెద్ద document ని చిన్న sections గా divide చేస్తాం. ఒక్కో section ని Chunk అంటాం.

Chunk size అంటే ఏమిటి?

ఒక్క chunk లో ఎంత text ఉండాలో నిర్ణయించే parameter. మన learning project లో ప్రస్తుతం 20 words per chunk ఉపయోగిస్తాం. Production లో token-aware లేదా semantic chunking కూడా ఉపయోగించవచ్చు.

Chunk overlap ఎందుకు అవసరం?

ఒక sentence రెండు chunks మధ్యలో విడిపోతే context కోల్పోయే అవకాశం ఉంటుంది. అందుకే previous chunk లోని కొన్ని words ని next chunk లో మళ్ళీ ఉంచుతాం. దీనినే overlap అంటాం.

ParameterValue
Chunk size20 words
Overlap5 words
Step15 words

మొదటి chunk 1–20 words, రెండో chunk 16–35 words. Size 6, overlap 2 అయితే మొదటి chunk [1,2,3,4,5,6], రెండో chunk [5,6,7,8,9,10].

Step 9 — Complete chunker.py

Python
def chunk_text(
    text: str, chunk_size: int = 20, overlap: int = 5
) -> list[str]:
    if chunk_size <= 0 or not 0 <= overlap < chunk_size:
        raise ValueError("Require 0 <= overlap < chunk_size")

    words = text.split()
    chunks = []
    step = chunk_size - overlap

    for start in range(0, len(words), step):
        end = start + chunk_size
        chunks.append(" ".join(words[start:end]))
        if end >= len(words):
            break

    return chunks


def create_chunks(source: str, text: str) -> list[dict[str, str]]:
    return [
        {"id": f"{source}:{index}", "source": source, "text": chunk}
        for index, chunk in enumerate(chunk_text(text), start=1)
    ]

Step 11 — Complete main.py

Python
from pathlib import Path
from loader import load_documents
from preprocessor import clean_text
from chunker import create_chunks


def main():
    print("RAG Application Started")

    data_directory = Path(__file__).resolve().parent / "data"
    documents = load_documents(data_directory)
    print(f"Loaded {len(documents)} documents")
    all_chunks = []
    for name, content in documents.items():
        cleaned_content = clean_text(content)
        all_chunks.extend(create_chunks(name, cleaned_content))

    print(f"Created {len(all_chunks)} chunks")
    for chunk in all_chunks:
        print(f"\nChunk: {chunk['id']}")
        print(f"Source: {chunk['source']}")
        print(chunk["text"])


if __name__ == "__main__":
    main()
