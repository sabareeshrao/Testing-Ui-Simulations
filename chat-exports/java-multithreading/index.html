Java Multithreading

Interview question: What is multithreading? How do you create and start a thread in Java?

1. What is multithreading?

Multithreading is the ability of a program to execute multiple threads concurrently within the same process.

A thread is an independent path of execution within a program.

■
Shared memory
■
Independent execution

Threads share heap memory but have their own execution stacks and program counters.

5. How do you create a thread in Java?

There are two classic approaches.

Method 1 — Extending the Thread class

java
class MyThread extends Thread {

    @Override
    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {
    public static void main(String[] args) {

        MyThread t1 = new MyThread();

        t1.start();
    }
}
new MyThread()
Create a thread object
t1.start()
Start a new thread of execution
run()
Execute the task on that thread

Method 2 — Implementing the Runnable interface

java
class MyTask implements Runnable {

    @Override
    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {
    public static void main(String[] args) {

        MyTask task = new MyTask();

        Thread t1 = new Thread(task);

        t1.start();
    }
}
Runnable
Defines what work to perform.
Thread
Provides a separate path of execution.

Method 3 — Using a lambda expression (Java 8+)

A shorter way of implementing Runnable.

java
Thread t1 = new Thread(() -> {
    System.out.println("Thread is running");
});

t1.start();

All three examples start a new thread using start().

8. Thread lifecycle

Java provides six official thread states through Thread.State.

Simplified lifecycle. A waiting or blocked thread can return to RUNNABLE when the relevant condition is satisfied.
StateMeaning
NEWObject created, not started
RUNNABLEReady or executing
BLOCKEDWaiting to acquire a monitor lock
WAITINGWaiting indefinitely for another action
TIMED_WAITINGWaiting for a specified duration
TERMINATEDExecution completed

Running is not a separate official Java thread state. It is included in RUNNABLE.

10. Creating and starting multiple threads

java
public class Main {

    public static void main(String[] args) {

        Runnable task = () -> {
            for (int i = 1; i <= 3; i++) {
                System.out.println(
                    Thread.currentThread().getName()
                    + " : " + i
                );
            }
        };

        Thread t1 = new Thread(task, "Worker-1");
        Thread t2 = new Thread(task, "Worker-2");

        t1.start();
        t2.start();
    }
}
Possible console output

Thread execution order is not guaranteed. Different executions may produce different output orders.

12. What is join()?

It makes the calling thread wait until the specified thread finishes.

16. Final interview answer

Multithreading in Java is the concurrent execution of multiple threads within a single process, allowing multiple tasks to make progress independently.

We can create a thread by extending the Thread class or implementing the Runnable interface and passing its instance to a Thread object.

We override or implement the run() method to define the task and call start() to begin execution on a new thread.

Runnable is generally preferred because it separates the task from thread management and supports better flexibility. Calling run() directly does not start a new thread.

17. Complete mental model

Remember: run() defines the work. Thread provides the execution path. start() begins execution on a new thread.
