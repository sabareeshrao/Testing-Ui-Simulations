Merge Sort — Data Structures & Algorithms

Merge Sort is a sorting algorithm that uses the divide and conquer technique. It repeatedly divides an unsorted array into smaller arrays, sorts them, and merges them back together in sorted order.

1. Divide and conquer

Divide
Split the array into two halves.
Conquer
Recursively sort each half.
Combine
Merge the sorted halves.

An array with zero or one element is already sorted. This is the base case that stops the recursion.

2. How Merge Sort divides an array

Each recursive call works on a contiguous part of the original array.

5. How recursion returns sorted arrays

Conceptual bottom-up view of the merge levels. Recursive execution completes individual subtrees before returning to their parents.

The recursive calls return sorted halves. Their parent call merges them into a larger sorted array.

6. Merge Sort implementation in Python

def merge_sort(arr):
    if len(arr) <= 1:
        return arr.copy()

    mid = len(arr) // 2

    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)


def merge(left, right):
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])

    return result


numbers = [38, 12, 27, 43, 9, 31, 18, 25]
print(merge_sort(numbers))

8. Is Merge Sort stable?

Yes. Merge Sort is stable when equal elements from the left half are selected before equal elements from the right half.

5A appears before 5B originally and remains before 5B after sorting.

The <= comparison in the merge function is important. Using < and selecting from the right on equality can break stability.
