What is an embedding? It is a fixed-length list of numbers produced by a trained model. Each number is one coordinate in a learned space; together, the numbers help represent relationships between words, sentences, or other inputs. They are not a readable translation of the original text.

1. Explore the semantic space

A useful embedding model often places related concepts near one another, even when they use different words. Select Dog, Car, or Pizza to see a simplified example. Real embeddings live in many dimensions, not just two.

2. How text becomes a vector

First, a tokenizer splits text into tokens. The embedding model processes their representations and creates a vector for the input. Depending on the model, it may combine contextual token vectors into one sentence-level vector.

3. Cosine similarity playground

Cosine similarity compares direction rather than vector length. Vectors pointing the same way score +1, perpendicular vectors score 0, and opposite vectors score −1. In actual embedding systems, a high score suggests a stronger match, but there is no universal cutoff.

4. Embeddings inside RAG

RAG typically embeds and stores document passages in a searchable index. When you ask a question, it creates a compatible question embedding and retrieves the closest passages. The LLM receives the original retrieved text to help answer—not just the vector numbers.

Remember: An embedding represents information as a vector. Related meanings often have similar vectors, making semantic search possible.
