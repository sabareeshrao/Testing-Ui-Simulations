Amazon EC2

An Elastic Compute Cloud instance is a virtual server you can start in AWS, configure, and use to run websites, apps and services.

3. Security groups: which traffic gets in?

A security group is an instance-level virtual firewall. Turn inbound rules on or off, then test whether a request is allowed. For SSH, restrict access to your own IP rather than everyone.

Inbound firewall playground

This tests security-group inbound rules only, not a real connection. The server must also be running, reachable, and listening on that port. Security groups are stateful, so permitted connections can receive response traffic.

6. How do you connect?

For a Linux EC2 instance, you can use a supported browser-based connection method or SSH. SSH uses a private key and an allowed network path.

Example: SSH to Amazon Linux

EXAMPLE ONLY
ssh -i "my-key.pem" ec2-user@YOUR_PUBLIC_IP
✓ Keep the private key secure. Allow SSH from your IP only, and use the correct default username for your AMI. You can also consider AWS Systems Manager Session Manager to avoid opening inbound SSH.

Example placeholders are not an actual server or a valid connection address. The simulator never makes network calls.

Remember: An EC2 instance is a configurable cloud server. The AMI supplies the system image, instance type sets compute resources, the security group controls allowed connections, and EBS provides block storage.
