Gradient Descent

Gradient Descent is an optimization algorithm used to train machine learning models by gradually adjusting their parameters to minimize prediction errors.

It is one of the fundamental concepts behind machine learning, deep learning, neural networks and LLM training.

Loss function · Parameter updates · Minimum

The objective is to reach a set of model parameters that produces a low loss.

5. What is a gradient?

A gradient describes how a function changes as its input parameters change. For a function with one parameter, this is simply its derivative or slope.

L(w) = (w − 3)²
dL/dw = 2(w − 3)

A zero gradient indicates a stationary point. It is not necessarily a minimum in a general loss function.

The derivative of loss with respect to the parameter.

Why do we subtract the gradient?

The gradient points toward the direction of steepest local increase in loss. Subtracting it moves in the opposite direction, toward steepest local decrease.

For multiple parameters, the gradient contains a partial derivative for every trainable parameter.

∇L = [ ∂L/∂w₁, ∂L/∂w₂, …, ∂L/∂wₙ ]ᵀ

All the parameters can be updated together using their respective gradients.

14. Advanced gradient descent optimizers

Basic gradient descent has limitations. Advanced optimizers introduce additional mechanisms to improve training behavior.

Vanilla gradient descent
Uses the current gradient directly.
Momentum
Accumulates previous gradient information to smooth updates and accelerate movement in consistent directions.
AdaGrad
Adapts the learning rate of each parameter using accumulated squared gradients.
RMSProp
Uses a moving average of squared gradients to adapt parameter updates.
Adam
Combines estimates of first and second gradient moments to calculate adaptive updates.
AdamW
Separates weight decay from Adam's adaptive gradient update.

Adam and AdamW are commonly used for deep learning and transformer training, although optimizer selection depends on the task.

15. Challenges in gradient descent

Real neural network loss landscapes are much more complicated than a simple quadratic curve.

Local minimum vs global minimum
A local minimum is lower than nearby points. A global minimum is the lowest point in the entire domain.
Saddle point
A stationary point that increases in one direction and decreases in another.

Vanishing and exploding gradients

Vanishing gradients
Gradients become extremely small, making some weights learn very slowly.
Exploding gradients
Gradients become excessively large, potentially destabilizing training.
Vanishing gradients
Suitable initialization, residual connections and activation functions.
Exploding gradients
Gradient clipping, initialization and learning-rate adjustment.
Slow convergence
Learning-rate tuning, normalization and appropriate optimizers.
Flat regions and saddle points
Momentum, stochastic updates and suitable optimizer settings.

These techniques can mitigate optimization problems, but they do not guarantee convergence to a global minimum.

18. Implement gradient descent from scratch in Python

You do not need a machine learning framework to understand the basic algorithm.

python
def loss(w):
    return (w - 3) ** 2


def gradient(w):
    return 2 * (w - 3)

How it works in PyTorch

PyTorch
Automatic differentiation and model optimization
python
import torch

w = torch.tensor(0.0, requires_grad=True)

optimizer = torch.optim.SGD(
    [w],
    lr=0.1
)

for step in range(100):

    optimizer.zero_grad()

    loss = (w - 3) ** 2

    loss.backward()

    optimizer.step()

print(w.item())
