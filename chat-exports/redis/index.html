Redis

Redis is a high-speed, in-memory data store used for caching, session management, counters, leaderboards and messaging.

Unlike traditional disk-oriented databases, Redis primarily stores its working data in RAM.

Where Redis sits in an application

Redis can serve frequently requested data without repeatedly querying the primary database.
