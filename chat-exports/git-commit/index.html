Git Commit

Git Commit అంటే మన project లో చేసిన changes ని ఒక checkpoint లాగా Git history లో record చేయడం. ప్రతి commit లో staged files యొక్క snapshot, message, author, timestamp మరియు parent commit reference ఉంటాయి.

3. What exactly gets committed?
git commit అనేది working directory లో ఉన్న ప్రతి change ని save చేయదు. Staging area లో ఉన్న version మాత్రమే కొత్త commit లో record అవుతుంది.
Try this in the simulator: Edit App → Stage App → Edit App again → Commit.


4. Inside a commit
commit 8f3a2b1...
Author: Developer <dev@example.com>
Date:   Tue Nov 24 17:09:00 2026

    Add login endpoint
Commit hash అనేది Git object content ఆధారంగా తయారయ్యే identifier. Git internally tree ద్వారా file snapshots ని reference చేస్తుంది. మారని files ని ప్రతి commit లో physically duplicate చేయాల్సిన అవసరం లేదు.
Illustrative output from git log; the displayed hash is abbreviated.


5. Git commit vs Git push
git commit
Local Git history లో snapshot create చేస్తుంది.
Internet అవసరం లేదు.
git commit -m "Add login"
git push
Local commits ని remote repository కి పంపుతుంది.
Remote access అవసరం.
git push origin main
GitHub website ద్వారా commit చేస్తే ఆ commit GitHub repository లోనే create అవుతుంది. Local Git commit మాత్రం push చేయకపోతే GitHub లో కనిపించదు.


6. Important Git commands
git status
Working directory మరియు staging area status చూపిస్తుంది.
git diff
Unstaged changes చూపిస్తుంది.
git add App.java
App.java current version ని stage చేస్తుంది.
git diff --cached
Next commit లో record కాబోయే staged changes చూపిస్తుంది.
git commit -m "Add login API"
Staged snapshot తో commit create చేస్తుంది.
git log --oneline
Commit history ని compact format లో చూపిస్తుంది.
git show HEAD
Latest checked-out commit details మరియు diff చూపిస్తుంది.
git push origin main
Local main branch commits ని GitHub remote కి పంపిస్తుంది.


గుర్తుపెట్టుకో: Edit → Stage → Commit → Push. Git commit = local project history; Git push = remote synchronization.
