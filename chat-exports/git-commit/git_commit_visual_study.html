Git Commit

A commit is a saved snapshot of your project's staged changes at a particular point in time.

Think of it as a checkpoint in your project's history that you can revisit later.

Each commit creates a new checkpoint without removing previous checkpoints.

Imagine you are building an AI chatbot.

Every completed change can be saved as a commit. Together, these commits form the project's version history.

5. What is a commit hash?

Every Git commit has a unique identifier generated using a hashing algorithm.

Example SHA-1 commit hash · 40 hexadecimal characters
b83d21f4a9c82e701f6d32b8c945a176e20d3f91
Git commonly displays an abbreviated hash when it is sufficient to identify the commit uniquely.

You can use the hash to inspect a specific commit.

git show b83d21f

6. How Git tracks changes

Suppose you modify your chatbot configuration.

This comparison is called a diff. Git commits represent snapshots, while diffs show the differences between snapshots.

7. Does every commit duplicate the entire project?

No. Git can reuse unchanged file objects across multiple commits.

All three commits reference the same unchanged README file object. Modified files receive new objects.

This content-addressed storage helps Git maintain project history efficiently.

Commit lesson

GitHub Pages deployment

The commit records the lesson in the repository's history. GitHub Pages separately deploys the website.

12. What if you make a bad commit?

Undo changes with git revert
git revert <commit-hash>
Revert creates a new commit that reverses the selected changes while preserving history.
CommandPurpose
git revertReverse changes with a new commit
git resetMove the current branch to another commit
git commit --amendReplace the latest commit

Prefer git revert when undoing commits already shared with other developers.

13. Important Git commit commands

git status
Inspect working and staged changes.
git add .
Stage changes in the current directory.
git commit -m "Add RAG"
Commit staged changes with a message.
git log --oneline
View abbreviated commit history.
git show HEAD
Inspect the current commit.
git diff
Inspect unstaged changes.
git diff --staged
Inspect changes ready to commit.
git push origin main
Push the main branch to the remote.
